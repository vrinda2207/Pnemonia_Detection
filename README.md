# Pneumonia Detection using Deep Learning

A medical image classification project for detecting pneumonia from chest X-ray images using machine learning and deep learning techniques. The project implements and compares DenseNet121, EfficientNet, ResNet50, Vision Transformer, SVM, Random Forest, and reinforcement learning approaches. It achieved approximately **82% classification accuracy** and includes comparative analysis to identify the best-performing architecture.

### Tech Stack

* Python
* TensorFlow
* OpenCV
* CNN / Deep Learning
* Vision Transformer
* Machine Learning
* Reinforcement Learning
* Chest X-ray Image Processing

### Key Highlights

* Built a complete chest X-ray classification pipeline.
* Compared multiple ML and DL architectures.
* Applied image preprocessing and computer vision techniques.
* Achieved approximately **82% classification accuracy**.
* Performed comparative model analysis.
