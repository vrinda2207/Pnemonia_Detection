# Pneumonia Detection using Deep Learning

## Overview

A medical image classification project for detecting pneumonia from chest X-ray images using Machine Learning and Deep Learning techniques. The project implements and compares multiple models to identify an effective approach for pneumonia classification.

## Models Implemented

* DenseNet121
* EfficientNet-B0
* ResNet50
* Vision Transformer (ViT)
* Support Vector Machine (SVM)
* Random Forest
* Reinforcement Learning
* A2C (Advantage Actor-Critic)

## Tech Stack

* Python
* TensorFlow / Keras
* Scikit-learn
* OpenCV
* NumPy
* Pandas
* Matplotlib
* Deep Learning
* Computer Vision

## Key Features

* Chest X-ray image preprocessing
* Pneumonia and normal image classification
* Implementation of multiple ML and DL architectures
* Comparative analysis of model performance
* Evaluation using classification metrics
* Exploration of reinforcement learning approaches

## Results

The implemented models were evaluated using classification metrics, with the project achieving approximately 82% classification accuracy.

## Objective

To develop an automated pneumonia detection system using chest X-ray images and compare different machine learning and deep learning approaches to determine an effective classification model.
